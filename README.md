# DentaLux — Стоматологическая клиника

Современный многостраничный сайт стоматологической клиники DentaLux, построенный на Next.js.

## Технологии

- **Next.js 16.3.8** (App Router) + TypeScript
- **Tailwind CSS v4** — утилитарные стили
- **Framer Motion** — анимации при скролле и переходах
- **react-hook-form + zod** — валидация форм
- **next/image** — оптимизированные изображения

## Начало работы

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка проекта
npm run build

# Запуск production-сервера
npm start
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Заявки и WhatsApp

По умолчанию проект работает как портфолио-демо (`NEXT_PUBLIC_PORTFOLIO_DEMO=true`). Формы проверяют введённые данные в браузере и показывают демонстрационный результат; заявки не сохраняются и не отправляются. Серверные API отвечают отказом на попытку отправки. Контакты и отзывы вымышлены, а страницы закрыты от индексации. Для реальной клиники установите `NEXT_PUBLIC_PORTFOLIO_DEMO=false` и настройте подтверждённые данные и постоянное хранилище.

Формы сохраняют заявку на сервере и предлагают кнопку «Отправить в WhatsApp». Кнопка открывает чат с готовым текстом; посетитель сам отправляет сообщение. Сайт не утверждает, что сообщение уже отправлено или время забронировано. Администратор подтверждает запись в чате. Быстрая заявка отдельно помечается как `callback`, полноценная — как `appointment`.

Рабочий номер задаётся в `.env.local` через `NEXT_PUBLIC_WHATSAPP_NUMBER` (только цифры с кодом страны). По просьбе владельца оставлен демонстрационный номер `77271234567`; он не проверен и не предназначен для реальных пациентов. После изменения публичной переменной пересоберите сайт.

В режиме разработки заявки находятся в `.private/leads`, вне публичных файлов и Git. Каждая заявка сохраняется в отдельный JSON-файл с уникальным номером, временем и статусом `pending_whatsapp`. Этот статус означает подготовку сообщения, а не доставку в WhatsApp. Имена и телефоны не выводятся в журналы приложения. Доступ к каталогу на Windows нужно ограничить учётной записью сервера; резервные копии и удаление записей настраивает оператор.

Для production обязательно задайте `LEADS_DIRECTORY` — абсолютный путь к постоянному закрытому каталогу с правами записи. Локальный `.env.local` уже настроен для запуска в этой папке. Не используйте временную папку serverless-хостинга: для такого размещения потребуется внешняя база данных. Без настроенного постоянного каталога API возвращает ошибку, вместо ложного подтверждения. Текущая реализация рассчитана на один Node.js сервер; ограничение повторных заявок действует внутри процесса и не заменяет защиту от спама на хостинге.

Дата и время означают пожелание пациента. Часы учитывают график Алматы: будни 09:00–21:00, выходные 10:00–18:00. Живого расписания занятости врачей нет. Выбор доступен на следующие 14 дней; врач проверяется на соответствие услуге.

## Проверки

```bash
npm run lint
npm test
npm run build
```

Тесты проверяют телефон, согласие, часовой пояс и график, сочетания врача и услуги, сохранение заявки, WhatsApp-текст, ошибки формата, ограничение объёма запроса, сбой хранилища и повторные заявки. Для тестовых файлов используется отдельный временный каталог, который очищается после проверки.

## Перед публикацией

Замените демонстрационные контакты, демонстрационные портреты врачей и сведения о клинике на подтверждённые материалы. Уточните реквизиты оператора и срок хранения данных на странице `/privacy`. Раздел `/cases` показывает подписанные иллюстрации процедур. Фотографии реальных результатов ещё не опубликованы; вымышленные изображения «до/после» не используются. Сайт не содержит административной панели: заявки доступны оператору через закрытый каталог сервера и сообщения, отправленные посетителями в WhatsApp.

Изображения оптимизируются Next.js в WebP/AVIF. Превью ссылок генерируется по `/opengraph-image`, значок сайта — `app/icon.svg`. Единственный глобальный файл стилей — `styles/globals.css`. Старые скрипты `update-design.mjs` и `smooth-animations.mjs` являются инструментами массовой замены; не запускайте их для текущего дизайна без просмотра изменений.

Фотографии блога, акций, врачей и клиники хранятся в `public/images`. Внешние запросы к фотобанку при открытии сайта не нужны. Портреты и интерьер — демонстрационные фотографии из первоначальных источников Unsplash; обложки статей и акций используют тематические фотографии услуг. Скрипт `scripts/cache-photos.mjs` предназначен только для повторного скачивания исходных пяти фотографий, не выполняется при сборке или запуске сайта.
